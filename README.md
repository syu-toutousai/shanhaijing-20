**在线阅读**：<https://syu-toutousai.github.io/shanhaijing-20/>

## 更新方式

1. 在 `index.html` 中复制一讲的 `<article>` 结构，填入新讲内容。
2. 把目录里对应的 `.lec.locked` 改为 `<a class="lec" href="#lec-XX">`，状态改为“已更新”。
3. 更新首屏的“已更新 00–01”与 footer。
4. 推送 `main`，GitHub Pages 自动部署。
